# 24. Swap Nodes in Pairs

Given a linked list, swap every two adjacent nodes and return its head.

You must solve the problem without modifying the values in the nodes. Only the nodes themselves may be changed.

If the linked list contains an odd number of nodes, the last node remains in its original position.

## Example 1

**Input:**
head = [1,2,3,4]

**Output:**
[2,1,4,3]

## Example 2

**Input:**
head = []

**Output:**
[]

## Example 3

**Input:**
head = [1]

**Output:**
[1]

## Constraints

* The number of nodes in the list is `n`.
* `0 <= n <= 100`
* `0 <= Node.val <= 100`
